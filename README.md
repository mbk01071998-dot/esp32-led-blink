ESP32 LED Blink Project
Project Description

This is my first Embedded Systems project using ESP32 and PlatformIO.

Components Used
ESP32 Development Board
LED
220 Ohm Resistor
Breadboard
Jumper Wires

Working Principle
The LED is connected to ESP32 GPIO pin 2.

LED ON for 10 seconds.
LED OFF for 10 seconds.
This process repeats continuously.

Programming
Language: Embedded C++
IDE: Visual Studio Code
Framework: Arduino
Platform: PlatformIO
